# Feedwell

一个简洁、原生体验的 macOS RSS 阅读器，尊重原始网页设计。

**[English](README.md)**

![Feedwell 截图](docs/screenshot.png)

## 为什么做 Feedwell？

大多数 RSS 阅读器把文章剥离成纯文本，把每个博客都磨成了千篇一律的样子。但很多作者在网站设计上花了很多心思——定制字体、交互式演示、代码演练场、精心打磨的排版。Feedwell 的做法不同：除了传统的 RSS 文章渲染，还可以通过内置 webview **直接打开原始网页**，让你获得作者期望的完整阅读体验。

这也意味着你关注的博客能获得真实的页面访问量——一种对创作者的小小支持。

## 功能

- **三栏布局** — 侧边栏、文章列表、阅读器一窗口搞定
- **Webview 模式** — 每个订阅源可单独开启"打开原始网页"
- **智能文件夹** — 全部、未读、已收藏筛选
- **文件夹分组** — 拖拽整理订阅
- **独立刷新频率** — 每个订阅源可配置不同的刷新间隔
- **OPML 导入导出** — 订阅随你走
- **统计面板** — 月度趋势、订阅源健康监控、异常检测
- **键盘快捷键** — j/k 导航、标记已读、收藏、刷新等
- **深色模式** — 跟随系统偏好
- **虚拟滚动** — 轻松应对数千篇文章

## 技术栈

- **Electron** + **React** + **TypeScript**
- **SQLite** (better-sqlite3)
- **electron-vite** 快速开发构建
- **react-virtuoso** 虚拟列表

## 快速开始

### 前置条件

- Node.js >= 18
- pnpm

### 安装与运行

```bash
pnpm install
pnpm dev
```

### 打包

```bash
pnpm package
```

在 `dist/` 目录下生成通用 DMG。
